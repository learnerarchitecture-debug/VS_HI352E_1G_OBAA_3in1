OBAA Launcher — Modern UI concept · v1.1

Dark glass design · D-pad-first TV navigation · built for the SP352 / Hi3751V352E board (Android 9, 1 GB RAM, 720p UI).
Hover any tile to feel the focus effect. Screens shown at 1920×1080 (device scales to 1280×720).
Branding: “OBAA Launcher — powered by android — V1.1” on Home, About, and boot splash.
Auto-update: Settings → Software update, checks a public GitHub repo (Releases API), silent install as system app.
Focus model: big scale + white ring + soft blue glow — everything reachable with the 8890 remote.
Lightweight: static gradient art, no live blur on device, cached app icons (1 GB RAM safe).
Inputs row: Live TV · HDMI · Media · Settings — one press away.
Motion: rows fade at edges, 180 ms scale/glow, no heavy animation.
Palette — accent blue, accent violet, deep background, success green, text white. Focus ring is always plain white for maximum contrast on TV panels.
